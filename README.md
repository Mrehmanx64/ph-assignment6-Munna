# FitLog

FitLog is a dark, no-nonsense gym companion designed to help you track your workouts, plan your sets, and reach your fitness goals efficiently.

## Technologies Used
- Next.js (App Router)
- React 19
- Tailwind CSS
- DaisyUI
- TypeScript

## Key Features
1. **Workout Library**: Browse 12 diverse lifts with detailed stats (duration, calories, rating).
2. **Personalized Planning**: Create a daily plan by adding your favorite lifts, with a cap for focused training.
3. **Saved Workouts**: Keep a list of workouts you want to try later.
4. **Interactive Dashboard**: Track your daily progress with live metrics for exercises, minutes, and calories.
5. **Responsive Design**: Seamless experience across mobile, tablet, and desktop devices.
